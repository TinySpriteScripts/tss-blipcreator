# Blip previews

These PNG previews belong to tss-blipcreator, not tss_bridge. They are stock sprites
from the Cfx.re blip reference: https://docs.fivem.net/docs/game-references/blips/

Only the configured sprite choices are included. Replace `<sprite ID>.png` in
`blips/` to match your server's custom YTD textures. When adding a sprite choice,
add its matching PNG here too. The bridge displays the original image without
tinting it and shows a placeholder if it cannot load. These are static previews;
they do not automatically follow game texture replacements or blip colours.
